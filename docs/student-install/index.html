Install Lockedscreen

Two quick clicks. First trust the certificate, then install the app.

Step 1: Trust Certificate

Required one time so Windows trusts the app.

Download Certificate
After it opens:
Click Install Certificate → Current User → Trusted Root Certification Authorities → Finish.

Step 2: Install App

Uses App Installer to guide the setup.

Install Lockedscreen
When prompted:
Click Install.
If you see a security prompt, it means the certificate wasn’t installed yet. Go back to Step 1.
