# 0.6.63 Store Update

Hold the 0.6.62 package. Use the corrected 0.6.63 candidate and its validation
record; local WACK is not Microsoft certification or a live lockdown test.

1. Complete `v0.6.63-acceptance-guide.md` using the isolated local test shortcut.
   No GitHub download is necessary on the build PC.
2. Open https://partner.microsoft.com/dashboard and select the existing
   LockedScreen product. Keep the registered identity and publisher unchanged.
3. Create a **New package flight** for your and the other teacher's Store accounts.
   Under **Packages**, upload
   `apps/desktop/dist-store/LockedScreen-Store-0.6.63-x64.appx`.
   Expected identity: `WealthGate.LockedScreen`, version `0.6.63.0`, x64.
4. Add `v0.6.63-reviewer-instructions.md` under additional testing information.
   Confirm the privacy URL is https://auth.whsdominica.com/privacy. Resolve all
   Partner Center findings and submit the flight for certification.
5. After approval/publication, install the flight through Microsoft Store with
   each included tester account. Confirm 0.6.63 and repeat the supervised tests
   on that signed installation, including the fullscreen edges and post-submit PIN.
6. Only after acceptance, create a public submission update to the same product,
   use the validated package, review listing/reviewer information, and explicitly
   submit for certification/publication. Store updates use Microsoft Store, not
   the GitHub EXE updater.

The one combined APPX contains both workspaces. Its welcome role selection does
not reduce the Store download or run the online EXE role chooser. The GitHub
chooser downloads only the selected role; prereleases remain off stable updates.

Flight reference: https://learn.microsoft.com/en-us/windows/apps/publish/package-flights
