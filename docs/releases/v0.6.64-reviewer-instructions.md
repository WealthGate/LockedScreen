# Microsoft Store Additional Testing Information

LockedScreen 0.6.64 is a full-trust Windows examination app with native helpers.
This combined package contains teacher and student views. Teacher Google connection
uses publisher-hosted OAuth; schools do not need their own OAuth project by default.

Use a supervised spare PC with one display. Set and securely record a unique,
non-default invigilator exit PIN before starting. An imported package uses the
exporting teacher's PIN. Prepare a short native practice exam with known answers.

For Classroom testing, connect a teacher account before the exam, post the package
to a test class, save its assignment ID and enable student LMS turn-in. The enrolled
student signs in through Google's system-browser page BEFORE lockdown starts.
Cancellation must prevent exam startup; questions remain hidden until native
lockdown and physical fullscreen coverage are confirmed. Separate secure-desktop
launches use a Windows-encrypted, one-use authorization handoff with no credentials
in command-line arguments.

During the exam, teacher/settings/import views, alternate packages, external tools,
browser launches, screenshots and kiosk/navigation changes remain blocked. Protection
failure must pause the exam. Check physical screen edges and common task-switching
shortcuts at the device's actual display scale.

Submit saves the local result and automatically attempts configured LMS delivery
using prepared student authorization. It must NOT ask for an additional PIN, open
a browser, or release lockdown. Delivery and grade status are separate. Across-PC
automatic grade publication requires a configured authenticated teacher grade bridge;
student consent cannot write teacher grades. Google consent/sensitive-scope approval
and school Workspace access policies still apply.

To leave, choose Invigilator unlock and enter the PIN. Blank/incorrect PINs must
not release before or after submission. Correct release restores desktop/keyboard
use. Do not use Task Manager as the normal exit. Temporary student authorization
expires after at most twelve hours; normal exit requests deletion from the service.

Review the exact 0.6.64 WACK findings in the validation record, not older reports.
The full-trust app and native/.NET/Electron helpers use process-launch APIs. Optional
static-scanner findings are not claimed as Store-policy waivers. Unmanaged Home/Pro
cannot guarantee suppression of reserved secure-attention actions. Stronger school
deployments require supported managed kiosk/Keyboard Filter policies. The app does
not silently change Windows security or accessibility settings.
