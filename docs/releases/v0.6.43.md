# Lockedscreen 0.6.43

## Improved

- Desktop update checks now run every 30 minutes while the installed app is open, instead of every 4 hours.
- Update prompts now appear across the app, including student/session screens, without forcing installation.
- The `Remind later` action snoozes the same pending update for 30 minutes, then shows the prompt again if the update is still pending.
- The available-update message now makes it clear that users choose when to download and install.

## Mobile Note

- The Windows desktop updater cannot update Android/mobile installs. Mobile releases still need a separate Android delivery channel such as managed device deployment, APK sideloading, or an app-store/internal-test track.

## Validation

- Passed desktop tests.
- Passed desktop TypeScript checks.
