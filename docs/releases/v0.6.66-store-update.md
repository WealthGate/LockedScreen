# LockedScreen 0.6.66 Store Update

1. Complete `v0.6.66-acceptance-guide.md`, including actual Google authentication,
   return to the same Form, one-response enforcement and supervised native lockdown.
2. Open [Partner Center](https://partner.microsoft.com/dashboard), select the existing
   LockedScreen product and create a private flight for your test accounts.
3. Upload `apps/desktop/dist-store/LockedScreen-Store-0.6.66-x64.appx`. Expected identity:
   `WealthGate.LockedScreen`, publisher `CN=BCFD90EE-508A-4A52-BE8F-96555ACE47FA`,
   version `0.6.66.0`, x64. Do not change the registered publisher or create a new listing.
4. Add `v0.6.66-reviewer-instructions.md` under additional testing information and retain
   https://auth.whsdominica.com/privacy. Review all findings and submit the flight.
5. After flight approval, install through Microsoft Store and repeat sign-in, submit,
   record/retry, fullscreen, switching and PIN exit tests on each target PC type.
6. Only after acceptance, update the public Store submission with the validated APPX
   and explicitly submit for certification. WACK is not certification approval.

unsigned validation downloads. The APPX combines both workspaces; its welcome-page
role choice does not reduce the Store download size. The online installer still
