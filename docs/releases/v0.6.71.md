# LockedScreen 0.6.71

Teachers can now write a comprehension passage once and use it for several questions in an app-based exam. In **Question builder → Comprehension passages → Create passage**, enter a title and text. Assign existing questions by number, such as **1–10**, or create new questions for the passage. Students see the reading above each assigned question, including when they return to an earlier question.

**Teacher → Import → Download sample template** now provides a complete reading exercise with two questions and answer keys. You can put multiple passages and independent questions in the same document. Import review shows each passage with its assigned questions. The importer also accepts a question prompt on the line below `Question:` and reports incomplete tagged question blocks.

Passages travel inside the exam package and work offline alongside shared audio, images and video. Update both teacher and student installations before using passages in an exam.

Existing GitHub installations can select **Check for updates**. For a new installation, download **LockedScreen-Setup-0.6.71-x64.exe** and choose Teacher or Student. The GitHub installers are unsigned. [Release privacy policy](https://github.com/WealthGate/LockedScreen/blob/v0.6.71/PRIVACY.md)
