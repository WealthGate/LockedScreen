# LockedScreen 0.6.68: language questions and exam deadlines

## Teacher setup

1. Create an **app-based** exam. In the question editor, go to **Language audio**. Choose a listening clip (up to 5 MB), a play limit (1-10), and a speed (0.5x-2x). The audio travels in the exam package. Starting a clip counts as a play, even if the student leaves the question before it ends.
2. To collect speech, select **Allow a recorded answer for teacher review**. This adds an optional recording to the existing multiple-choice question; it does not automatically grade pronunciation. Save and export the package.
3. On a student PC, check Windows microphone privacy settings for desktop apps **before** the exam. Use headphones and a practice question. Students explicitly choose **Record answer**, may review or replace their recording, and have up to 60 seconds per answer.
4. On a teacher installation, open **Results** on the machine that recorded the answer to listen. For separate student PCs, configure student turn-in to an assigned Google Classroom or Microsoft 365 assignment before distributing the package. With successful turn-in, the teacher receives WebM audio attachments with the submission report. CSV and grade-only sync do not transfer recordings.

## Timeout and security

- At timeout, an app-based exam stops accepting edits, finishes an active recording, and submits the local answers. Configured student turn-in follows. Failed local saves can be retried without reopening questions. The invigilator PIN is still required to exit.
- A linked exam automatically saves the local session record. On a Google Forms responder page, LockedScreen can request submission by clicking a single visible, enabled final Submit control (English, French or Spanish). It does not advance sections, fill missing required answers, handle CAPTCHAs, bypass validation, or claim receipt. A school network outage or changed provider markup can prevent delivery. Check the provider's response list.
- Use an app-based exam for local automatic answer submission, or use the external LMS's own timed auto-submit. For Google Forms, instruct students to submit inside the form before the deadline. Keep one-response restrictions on.
- Remote exam sites cannot access the microphone. Linked exams do not control playback limits for media managed by the external site. No external browser, camera, screen capture or new navigation exception is required for language questions.
