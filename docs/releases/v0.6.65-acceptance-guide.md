# LockedScreen 0.6.65 Acceptance Tests

Use a practice exam and fictional student record. Keep the invigilator PIN available.
Do not test during a real assessment. The local shortcut is
`tmp/LockedScreen-0.6.65-Test.lnk`; no GitHub download is needed on the build PC.

## Native exam

1. Connect a teacher account and post a practice native exam to a practice class.
2. On a student device, open its exported package. Finish Google authorization
   before the exam begins. Cancelling sign-in must expose no questions.
3. Verify fullscreen coverage at the actual display scale, native protection and
   switching restrictions under supervision. No automated test proves every escape
   path on an unmanaged device. Do not claim Ctrl+Alt+Delete is blocked by the app.
4. Submit. Check the local score, Classroom attachment and configured grade route.
   Student consent alone cannot write grades; a teacher-authorized bridge is needed
   for cross-device native grade passback. No browser or PIN is needed for delivery.
5. Verify wrong exit PIN retains lockdown, correct PIN releases it, and device
   controls recover normally after exit.

## Linked exam controls

Use a practice form that is already compatible with embedded access. This tests
the controls, not signed-in Google Forms support. Do not weaken a real exam's
response restrictions to make this test pass.

1. Complete and submit the form using its own Submit button; check its confirmation.
2. Click Record online submission. The in-app confirmation must appear above the
   hidden form. Cancel must restore the form without saving or leaving lockdown.
3. Click again and choose Save session record. Expect Session record saved and a
   record ID. Repeated clicks must not create duplicate local records.
4. With a configured LMS binding, check session-report delivery. Its status must
   not imply Google verified the form answers or that LockedScreen graded them.
   Existing provider marks must not change to zero.
5. Test a delivery failure and retry. The saved record remains visible and locked.
6. Test protected Return to start and Restart form. Cancel leaves the form in place;
   confirm returns to the configured page. The exam timer must continue.
7. Test an expired session and an intentionally unavailable network. The local
   record must be saved or show a visible retryable error; no silent button failure.
8. Only the final invigilator PIN may exit. Test wrong and correct PINs.

## Signed-in Google Forms

Keep Limit to 1 response enabled. If embedded Google sign-in is requested, expect
the explicit unsupported-browser notice, with no unrestricted browser launch.
Classroom pre-exam OAuth does not establish a Forms website login. This is an
unresolved deployment constraint, not a passed acceptance test. Do not approve
this release as solving that workflow on personal/unmanaged Windows Home PCs.

Repeat applicable tests through a private Microsoft Store flight before public
submission. WACK validates package compatibility, not Google delivery or lockdown.
