# Lockedscreen v0.2.9

Release date: 2026-03-28

## Highlights

- Added student-side LMS turn-in with per-student OAuth after the secure local submission is recorded.
- Added package-level LMS assignment binding for Google Classroom and Microsoft 365.
- Added teacher-side assignment discovery so package setup can load classes and assignments from connected LMS accounts.
- Kept the existing local submission flow, lockdown session controls, protected `.lscp` package workflow, and teacher-side results sync pipeline intact.

## What Changed

- Local exam submission still completes first inside Lockedscreen.
- After local submission, students can sign in with their own Google Classroom or Microsoft 365 account and turn in directly from the app.
- Exported exam packages now include only public LMS app settings and assignment references needed for student sign-in.
- Teacher OAuth tokens remain on the admin device and are not exported with exam packages.
- Submission records now store LMS turn-in status so the post-submit screen can retry failed hand-ins.

## Security Notes

- This release does not remove or weaken the lockdown runtime.
- Student LMS sign-in happens after the secure submission is already saved locally.
- Student OAuth tokens are used in memory for the turn-in flow and are not stored in exported packages.
- Direct student turn-in is implemented for Google Classroom and Microsoft 365. The existing generic endpoint-based sync pipeline remains available for other LMS workflows.

## Installer Artifacts

- `Lockedscreen-Setup-0.2.9-x64.exe`
- `Lockedscreen-Portable-0.2.9.exe`

## Upgrade Notes

- Existing teacher result destinations continue to work.
- Existing protected package import/export continues to work.
- To use direct student LMS turn-in, update the package in Admin Console with the target LMS account, class, and assignment before exporting the package to students.
