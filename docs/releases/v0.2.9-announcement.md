# Lockedscreen v0.2.9 Announcement

Lockedscreen `v0.2.9` delivers the first complete LMS handoff flow on top of the existing secure local exam runtime.

This release adds document-driven exam creation, teacher LMS connections, central result sync options, and student-side LMS turn-in with per-student OAuth for Google Classroom and Microsoft 365. Exams can still be packaged, exported, opened in the installed app, completed inside the lockdown flow, and saved locally before any cloud turn-in begins.

## Highlights

- Import exam content from existing `.doc`, `.docx`, `.pdf`, and `.txt` files.
- Extract exam metadata and multiple-choice questions into the teacher workflow.
- Let teachers review imported questions and manually choose correct answers before saving.
- Connect teacher accounts to Google Classroom and Microsoft 365 with desktop OAuth.
- Bind exported exam packages to LMS classes and assignments without exporting teacher tokens.
- Allow students to sign in with their own LMS account after local submission and turn in directly from the app.

## Security Position

- The lockdown and local-first submission flow remains intact.
- Local submission completes before LMS turn-in starts.
- Teacher OAuth tokens stay on the admin device.
- Student OAuth tokens are used only for the live turn-in flow and are not written into exported packages.

## Recommended Release Message

Lockedscreen `v0.2.9` adds end-to-end LMS delivery support without weakening the secure exam path. Teachers can import exams from existing documents, connect Google Classroom or Microsoft 365, export packaged exams, and let students submit locally first before completing LMS turn-in with their own account.
