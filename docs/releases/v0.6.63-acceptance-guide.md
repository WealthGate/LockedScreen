# 0.6.63 Supervised Retest

Use a spare PC with the invigilator present. Close other work, disconnect extra
displays, and securely record a unique, non-default exit PIN before starting.
Do not rely on Task Manager as the normal exit procedure.

## Open The Candidate

- Local isolated shortcut: `tmp/LockedScreen-0.6.63-Test.lnk`.
- Store candidate: `apps/desktop/dist-store/LockedScreen-Store-0.6.63-x64.appx`.
- GitHub chooser: `apps/desktop/dist-editions/web/LockedScreen-Setup-0.6.63-x64.exe`.

The shortcut uses the Store candidate's unpacked application/native files and a
separate workspace. It does not replace your installed app or test Store signing.
For the real signed APPX installation, use a private Partner Center package flight.
Do not install a self-signed certificate just to bypass Windows trust checks.

## Prepare Google And The Exam

1. Check the app reports 0.6.63. Connect the teacher's Google account before the
   exam; the default hosted connection does not require school OAuth credentials.
2. Create a short native exam with a known score. Select the correct Classroom
   class, post it, and confirm the returned assignment ID is saved. Set assignment
   points in Classroom. Enable student LMS turn-in and export a fresh package.
3. Set the exam access password if needed, separately from the invigilator exit
   PIN. On a second PC, the exported package uses its exporting teacher's exit PIN.
4. Verify native diagnostics, then start only after Google windows and import or
   export dialogs have finished. Starting during a pending operation must refuse.

Hosted Forms may require browser sign-in that is not supported inside an embedded
exam browser. Do not add an external-browser exception during an active exam.

## Fullscreen And Lockdown

1. Start the practice exam from an ordinary nonmaximized window. Every screen
   edge must be covered: no desktop, title bar, taskbar or resize border.
2. Repeat at the actual Windows display scale used by students, including 125%
   or 150% where applicable. Restart the test app after changing display settings
   outside an exam. Forced command-line DPI simulations are not physical testing.
3. With supervision, test Alt+Tab, Alt+Shift+Tab, Alt+Esc, Alt+F4, Alt+Space,
   Ctrl+Esc, Ctrl+Shift+Esc, Windows, Windows+Tab/D/E/R/L, Ctrl+Tab/L/N/O/R/W,
   browser navigation, F11/F12 and Print Screen. Repeat right-side modifiers and
   held keys. Normal answers, typing and Tab navigation must continue to work.
4. Attempt app view changes, a second package, close actions, help links and
   external tools. None may weaken the active exam. Protection failure must pause
   the exam, not continue unlocked. Blank/wrong PINs must never release it.
5. Test mouse/touch edges and the school's actual keyboard, IME and accessibility
   configuration. Reserved secure-desktop actions require supported managed
   Windows policies; unmanaged Home/Pro is not an absolute-lockdown deployment.

## Submission, PIN And LMS

1. Submit and verify the saved local score/answers. Submission alone stays locked.
2. Choose the top **Invigilator unlock** button. It should offer **Release and
   turn in** when the saved result has pending configured LMS delivery.
3. Try a wrong PIN first: no browser, no release, no lost result. Enter the correct
   PIN: lockdown ends, then the system browser opens for student Google sign-in.
   Do not leave an unsubmitted exam in order to perform OAuth.
4. Finish sign-in with the enrolled student account. Confirm the result screen
   stays open and Classroom receives the report under the correct assignment and
   student. Cancel sign-in once as a separate test: the saved result must remain
   available for retry, not vanish into the dashboard.
5. Verify the grade separately. On a teacher-authorized test PC, expect the score
   scaled to the assignment points (for example 50% becomes 10/20). A temporary
   grade failure offers **Retry grade sync**, without a duplicate attachment.
6. A separate Student installation cannot use student consent to write teacher
   grades. Configure/test the authenticated teacher grade bridge for automatic
   across-PC grades, or use the teacher's authorized grade workflow. A successful
   turn-in alone is not confirmation that a grade was published.
7. Exit normally and verify the taskbar, keyboard and ordinary window size return.
   Reopen the saved result, then run a second exam and repeat wrong/right PINs.

Record PC/Windows edition, source, display scale, shortcut outcomes, PIN recovery,
Google sign-in, assignment ID, attachment and grade before Store publication.
