# Lockedscreen v0.6.45

Release date: 2026-06-17

## Highlights

- Added rich question authoring for formatted text, equations, fractions, powers, division, superscript, subscript, lists, and embedded question images.
- Added the same rich editor to import review so imported or OCR-extracted questions can be cleaned up before saving.
- Expanded student-side rendering for inline/display KaTeX math and sanitized embedded images in prompts and answer options.
- Updated downloadable and documented question templates with math and image examples.
- Made update alerts available to installed users outside active exam sessions so individuals can update from their own devices.

## Upgrade Notes

- This is the next update after `v0.6.44`.
- Publish the `0.6.45` installer, `.blockmap`, and `latest.yml` to the configured release location so installed `0.6.44` apps can detect the update.
- Existing exams and protected packages continue to load. Rich formatting is stored in the existing prompt and option content fields.
- Embedded images are stored as image data URLs inside the question content. Use reasonably sized PNG, JPG, GIF, or WebP files.
- Active app-based and linked exam sessions still hide update prompts until the session is no longer active.
