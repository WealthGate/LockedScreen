# LockedScreen 0.6.65 Validation

Candidate validation in progress on November 22, 2026. This version fixes linked
session controls; signed-in Google Forms remains unsupported in the embedded
browser on unmanaged PCs. It is not a complete resolution of that requirement.

TypeScript passed. Desktop/storage tests: 73 passed. Hosted OAuth tests: 10 passed.
The hosted service has no changes in this release and remains 0.6.64.

Browser fixtures passed 12 linked-control scenarios at 1360px and 390px: local save,
save failure/retry, expiry/retry, embedded sign-in rejection, navigation failure/retry
and delivery failure/retry. These use fictional IPC/webview fixtures, not real Google
accounts or physical keyboard hooks. Screenshots are local under
`tmp/acceptance-0.6.65-hosted-ui`.

Final package hashes, native/fullscreen tests, WACK and CI results will be recorded
after the immutable candidate is built. No old WACK result is reused. Live Google
and supervised native-lockdown tests remain required on target devices.
