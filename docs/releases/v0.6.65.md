# LockedScreen 0.6.65

Supervised-test candidate for linked exam submission controls. This update does
not add signed-in Google Forms support to the embedded exam browser.

- Record online submission opens a visible in-app confirmation, saves once and
  shows a local record ID. Save failures are visible and retryable.
- Protected return and restart use the same in-app confirmation. Restarting the
  form page does not restart the exam timer or change the provider's response limit.
- Expired sessions can retry a failed local save. Delivery failures can be retried
  without exiting lockdown. Only the invigilator PIN releases the exam.
- A Forms response URL is only a navigation hint, not proof of successful submission.
  Students must submit inside the form and check its own confirmation first.
- Linked session reports do not contain Google Forms answers or marks. They do not
  overwrite Classroom or Sheets grades with placeholder zero scores. The form
  provider remains responsible for answers, one-response enforcement and grading.
- Native exams retain pre-exam Google authorization and automatic configured LMS
  delivery after submission. No browser is opened inside an active locked exam.

## Google Forms limitation

Google Forms' Limit to 1 response requires a Google website session. Google can
block sign-in inside embedded applications. Classroom OAuth authorization is not
a website login and does not sign the embedded browser into Google Forms.
See [Google Forms settings](https://support.google.com/docs/answer/2839588) and
[supported browser guidance](https://support.google.com/accounts/answer/7675428).

On personal/unmanaged Windows PCs, including Windows Home, this version cannot
provide signed-in Forms inside its existing embedded lockdown architecture. Keep
the teacher's one-response restriction enabled. Do not use this candidate for
that workflow or claim it is fixed. A supported real-browser exam deployment
needs separate design and validation. No cookie copying, browser impersonation,
or mid-exam unrestricted external browser has been added.

The small online chooser still downloads the selected Student or Teacher installer.
The Store APPX is one combined package; Store role selection does not reduce its
download size. GitHub downloads remain unsigned test builds. Public Store and
stable update channels are not changed by this prerelease.
