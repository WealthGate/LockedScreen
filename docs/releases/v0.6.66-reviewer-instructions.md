# LockedScreen 0.6.66 Reviewer Instructions

LockedScreen is a Windows exam authoring and supervised student-runtime app. Use a
practice assessment on an isolated PC and know its configured invigilator exit PIN
before starting Full Kiosk Mode. The combined APPX contains both workspaces.

This update removes an app-side blanket Google account navigation block. Website
sign-in stays inside the same sandboxed exam browser with a checked return to the
configured assessment. Forms short links bind to the resolved Form. Search, mailbox,
Drive, account settings, other Forms and unapproved continuation/callback URLs stay
blocked. Approved popup navigation stays inside the existing view; no unrestricted
external browser is opened during an active exam. Native fullscreen and PIN exit
protections remain. The engine uses its genuine identity, not a spoofed Chrome or SEB.

Teacher Classroom connection uses publisher-hosted OAuth. Student LMS authorization
finishes in the system browser before lockdown. These API flows remain separate from
the Form's website login. Submission uses prepared authorization without another
browser or PIN; the final exit still requires the invigilator PIN.

For Forms, submit inside Google's page first and check its confirmation. Record
online submission saves a local session record, not Google answers or a verified
Google grade. Configured LMS delivery sends the session report without replacing
provider marks with placeholder zeros. Save/delivery failures have visible retries.

Google and school account policies still apply. The app's redirect/landing-page
test is not a claim that every Google account, website, SSO or 2FA flow is accepted.
Keep Google's one-response restrictions enabled. Full manual sign-in and supervised
recovery must be validated on the target devices before public deployment.

Privacy: https://auth.whsdominica.com/privacy
Microsoft Store updates do not invoke the GitHub installer. See the versioned
validation record for the fresh WACK result and remaining findings.
