# LockedScreen 0.6.61 Store Candidate

- New installations use publisher-managed hosted Google connection. Teachers connect
  their own Google account without creating a school OAuth project.
- The publisher Web client secret is server-side only. D1 teacher token records are
  encrypted with a separate Cloudflare Secret; local service credentials use the
  desktop's OS-encrypted vault.
- Optional school-managed Desktop OAuth is retained. Existing configured connections
  are not silently replaced.
- Teacher connection is rejected while an exam is active. Publisher-managed student
  turn-in requires a saved submission and invigilator-authorized release before an
  external browser opens. Submission itself does not release lockdown.
- Exported publisher-managed exam packages have no teacher session or publisher secret.
  Teacher start-code policy and Classroom assignment metadata are retained.
- Added service tests for PKCE proof, browser-state binding, one-time redemption,
  encrypted records, expiry, rate limits, Google JWT signatures, nonce, audience,
  permissions, and separate student authorization.
- The one-package Store build retains the registered Store identity and supports
  in-app role selection. It does not reduce the Store download based on a custom
  installer choice. GitHub's online installer remains a separate distribution path.

Deployment and tests are documented in [Hosted Google OAuth](../hosted-google-oauth.md).
Reviewer instructions are in [Additional Testing Information](v0.6.61-reviewer-instructions.md).
Live Google consent, assignment/grade delivery and supervised lockdown/exit acceptance
must pass before Store submission. Do not interpret the service health check as that
acceptance test.
