# LockedScreen 0.6.73

The floating exam toolbar shows the question count and keeps Add question, Save exam, and the top and bottom arrows within reach. Adding a question moves the editor to the new prompt. Teacher Import offers separate downloadable templates for standalone questions and a reading passage followed by multiple questions.

Graded exams now require an online school-account sign-in. The student’s name and email come from the signed-in account. Once that account starts a package, it cannot open a second attempt on another computer. To continue an interrupted app-based exam, use the original Windows profile, sign in to the same package and open **Invigilator resume authorization**. The invigilator enters the exam’s unlock PIN. Saved selections, flags, completed voice answers, question position and the original deadline are restored. A teacher can grant extra minutes when authorizing a resume. For website-hosted exams, the form provider controls answer recovery.

Teacher settings can enable a projector- and recording-friendly demonstration from the dashboard. Practice answers stay in the demonstration. The update also adds Ocean, Forest and Plum themes, password visibility controls and a new application icon.

Update teachers and students before distributing newly exported packages. Older app versions cannot open the new graded package format. Already distributed legacy packages can still be opened by older installations. GitHub installations can select **Check for updates**.
