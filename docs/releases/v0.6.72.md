# LockedScreen 0.6.72

Teachers can save an app-based exam directly after recording a listening prompt. Save exam includes completed recordings and shows which questions will receive them. During a microphone request or active recording, select Save exam to go to the question and cancel or stop recording. You can still preview or discard a take before saving.

Link-based exams accept website addresses such as forms.example.edu/quiz and save them as HTTPS links. Editing the exam updates the package address when it still matches the previous exam address. The editor accepts multiple allowed domains on separate lines.

If Windows temporarily blocks access to exam storage, the app keeps the existing file and lets you retry. Reading passages and shared images, audio and video remain available across their assigned questions.

Existing GitHub installations can select **Check for updates**. For a new installation, download **LockedScreen-Setup-0.6.72-x64.exe** and choose Teacher or Student.
