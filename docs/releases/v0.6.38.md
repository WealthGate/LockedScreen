# Lockedscreen 0.6.38

## Question Import

- Replaced the legacy typed-PDF reader with the current PDF.js engine.
- Added OCR fallback for scanned PDFs and clearer errors for protected, damaged, or unreadable PDFs.
- Added import support for Markdown, CSV/TSV, RTF, OpenDocument, PowerPoint, Excel, and HTML files.
- Kept support for TXT, DOC, DOCX, PDF, PNG, JPEG, TIFF, BMP, and WebP.

## Question Media

- Teachers can attach PNG, JPEG, or WebP images to individual questions.
- Teachers can attach audio to individual questions.
- Shared passages can provide one image and/or audio file to a group of related questions.
- Audio supports MP3, WAV, OGG, M4A, AAC, MP4, and WebM.
- Teachers can optionally limit the number of audio plays; blank means unlimited.
- Desktop and mobile learner runtimes enforce shared audio play limits across the exam session.
