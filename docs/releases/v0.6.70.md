# LockedScreen 0.6.70

Teachers can attach an audio clip, image or video once and share it across several questions in an app-based exam. In **Question builder → Shared media → Attach media**, choose a file up to 25 MiB and enter the questions that use it, such as `1–10` or `1, 3–5`. Use **Student preview** to check any question before exporting the exam.

Students can play or view the file on each assigned question. Audio and video keep their place when students move directly between questions that share the file. The media travels inside the exam package and works offline. Update both the teacher and student installations before distributing an exam that uses shared media.

The exam builder and import review now keep teachers’ work open if a save fails. Importing the same questions again creates distinct questions with independent answers.

For a listening question with a fixed playback speed or play limit, use **Language audio**. Teachers can also record and review their own prompts. A student microphone is used only when a student starts recording an answer on a question where the teacher enabled it.

Existing Windows GitHub installations can use **Check for updates**. For a new installation, download **LockedScreen-Setup-0.6.70-x64.exe** and choose Teacher or Student. The GitHub installers are unsigned and Windows may show a publisher warning.
