# LockedScreen 0.6.69: Teacher-recorded listening prompts

In **Create Exam**, open any app-based question and find **Language audio**.

1. Choose an audio file (up to 5 MB), or select **Record prompt** and speak for up to five minutes.
2. For a recording, select **Stop recording** and listen to the preview. Select **Use recording** to attach it, or **Discard recording** to keep the question's previous clip.
3. Set **Plays per attempt** (1 to 10) and **Playback speed** (0.5x to 2x), then select **Save exam**. Export the exam as usual. The audio travels with the question; it does not need a separate link.
4. To reuse your recording elsewhere, use **Download WebM clip** beside the attached clip and upload the file to another question.

If Windows denies microphone access, check its microphone privacy settings before recording or use the file upload instead. Recording a teacher prompt does not enable student microphones. Enable **Allow a recorded answer for teacher review** separately for a speaking question.

For linked exams such as Google Forms, the external provider owns the questions and the submission. Create a LockedScreen app-based question when you need these audio controls and automatic local submission on timeout. Ending a local linked session is not confirmation that an external form was submitted.
