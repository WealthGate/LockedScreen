# LockedScreen 0.6.63

Supervised-test prerelease. Replaces 0.6.62 for testing; do not submit the older
0.6.62 APPX, which could report fullscreen while leaving desktop edges exposed.

- Fix Windows exam sizing by entering fullscreen before locking resize controls.
  Confirm actual window and content coverage, refuse startup if it cannot be
  confirmed, and pause an active exam if coverage cannot be recovered.
- Restore the previous window geometry and controls after invigilator release.
- After a saved submission, the global invigilator unlock starts configured LMS
  turn-in instead of discarding the result screen and returning to the dashboard.
  The correct PIN releases lockdown before Google opens in the system browser.
- Retain the saved result and offer a grade-sync retry when turn-in succeeded but
  teacher grade publication failed. Do not duplicate an already turned-in report.
- Scale grades to Classroom assignment points. Do not write a guessed raw grade
  when the assignment points cannot be read, or zero for an unscored hosted test.
- Send the actual Classroom student-submission ID to configured grade bridges,
  not a Drive attachment URL.

The small online setup downloads only the chosen Student or Teacher installer.
The Store APPX is one combined package, not an on-demand role download. Publisher
Google OAuth remains hosted; its Web client secret is not shipped in the app.
Student authorization can turn in work, but cannot publish teacher grades.
Automatic grades across student PCs require an authenticated teacher grade bridge.

See the acceptance, validation, Store-update and reviewer files for 0.6.63 in
`docs/releases`. Real Google and supervised native lockdown tests remain release
gates. A normal Windows app cannot promise to suppress reserved secure-attention
actions on unmanaged Home/Pro devices. GitHub downloads are unsigned test builds;
this prerelease does not replace stable automatic updates or publish to the Store.
