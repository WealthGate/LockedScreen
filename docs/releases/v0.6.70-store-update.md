# Microsoft Store listing update for LockedScreen 0.6.70

## What’s new in this version

Teachers can now share one audio clip, image or video across several questions in an app-based exam. Assign a listening passage to questions 1–10 and students can keep listening as they move between them. Files travel with the exam and work offline. Teachers can preview each question before sharing. If saving an exam or importing questions fails, the editor keeps your work open so you can retry.

## Product feature

Share audio, images and video across selected questions, with continuous playback between questions that use the same file.

## Reviewer test

Create an app-based exam with three questions. Attach a short audio file to questions 1–2, preview all three, save the exam and export it. On an updated Student installation, open the package and start the exam. Play the audio on question 1, go to question 2 and confirm playback continues. On question 3 the file should disappear. Return to question 1 and confirm it is available again. Repeat with an image or video. Submit the exam and use the configured invigilator PIN to exit.
