  expired, mismatched or unrefreshable credentials never trigger interactive OAuth
  from the locked turn-in path. The invigilator PIN is still checked for final exit.

## Remaining Acceptance

Follow `v0.6.64-acceptance-guide.md` on supervised devices and a signed private
Store flight, including actual display scale, keyboard behavior, a real enrolled
student Google account, report attachment, expected grade and final PIN recovery.

Student authorization is not teacher grading authority. Across-PC automatic grades
still require the configured authenticated teacher grade bridge. Confirm publisher
Google External/In production AND requested sensitive-scope approval; these local
tests do not establish Google verification. School Workspace policy also applies.
Temporary student service credentials expire within twelve hours; interrupted/offline
sessions rely on server expiry if deletion cannot reach the service.

Unmanaged Home/Pro cannot guarantee reserved secure-attention suppression. Managed
Windows kiosk/Keyboard Filter, touch/IME/accessibility, multiple users and privileged
tampering require separate school deployment validation. Stable GitHub automatic
updates and the production Store submission remain unchanged until acceptance.
