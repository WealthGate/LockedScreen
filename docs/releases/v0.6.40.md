# Lockedscreen 0.6.40

## Fixed

- Fixed student Google Classroom turn-in failing after sign-in with a Google 404 response.
- Corrected the Classroom `modifyAttachments` action URL to use Google's required gRPC action syntax.
- Prevented raw Google HTML error pages from being displayed inside the student submission screen.

## User Update

- Installed copies of Lockedscreen `0.6.39` and earlier should update to `0.6.40`.
- The standard Windows installer supports an in-place update and preserves local application data.
- Existing local exam submissions remain saved and can be retried after updating.

## Validation

- Added automated coverage for Google Classroom student-submission action URLs.
- Passed desktop tests, TypeScript checks, and production Electron builds.
