# 0.6.64 Store Update

1. Finish `v0.6.64-acceptance-guide.md` with the local test shortcut. No GitHub
   download is necessary on this build PC. Check the final validation record.
2. Open https://partner.microsoft.com/dashboard and choose the existing LockedScreen
   product. Do not create another product or change its registered publisher.
3. Create a private package flight for your and the other teacher's Store accounts.
   Upload `apps/desktop/dist-store/LockedScreen-Store-0.6.64-x64.appx` under Packages.
   Expected identity: `WealthGate.LockedScreen`, version `0.6.64.0`, x64.
4. Add `v0.6.64-reviewer-instructions.md` under additional testing information.
   Keep the privacy URL https://auth.whsdominica.com/privacy. Review all Partner
   Center warnings/findings and submit the flight for certification.
5. After flight approval/publication, install through Microsoft Store using the
   included tester accounts. Confirm 0.6.64 and repeat the real Google, automatic
   submit, fullscreen/keyboard and wrong/right exit-PIN tests on that signed build.
6. After acceptance, update the existing public Store submission with the validated
   package, review listing/reviewer details, and explicitly submit for certification.

WACK is not Microsoft certification or proof of native lockdown. GitHub EXEs are
unsigned test downloads. Store customers update through Microsoft Store. The one
combined APPX contains both workspaces; it does not run the small online role chooser
or reduce its download according to welcome-page role selection.

Flight reference: https://learn.microsoft.com/en-us/windows/apps/publish/package-flights
