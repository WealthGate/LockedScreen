# Microsoft Store Additional Testing Information

LockedScreen 0.6.63 is a full-trust desktop exam app with native Windows helpers.
This combined package has teacher authoring and student examination views. The
publisher-hosted Google connection opens a system browser outside active exams;
school-owned OAuth credentials are optional, not required by default.

Use a supervised spare device, one display, and close other work. Set and securely
record a unique, non-default invigilator PIN before starting a short practice exam.
For imported packages use the exporting teacher's exit PIN, not an assumed default.

At exam startup the app verifies native filtering and fullscreen coverage of both
window and content. It refuses startup if these cannot be confirmed. It pauses
the exam if live protection cannot be recovered. Teacher/settings/import views,
external launches, screenshots, alternate exams and changes to navigation/kiosk
controls must remain blocked during a session. Verify all screen edges are covered
at the test device's normal display scale. Test blank/wrong PINs before and after
submission: neither may release the exam. Use normal invigilator release, not
Task Manager, to finish. Correct release restores ordinary keyboard/window use.

For Classroom, connect the teacher account and post a short native practice exam
before starting. Confirm its assignment ID and enable student LMS turn-in. Submit
the exam, verify the saved score, then choose **Invigilator unlock** followed by
**Release and turn in** with the correct PIN. Only after release may the external
Google sign-in open. The saved result remains visible for delivery status/retry.
Submission/attachment and grade status are distinct. Across-PC automatic grade
publication requires the configured authenticated teacher grade bridge; student
consent cannot write teacher grades. School Workspace policies and Google consent
or sensitive-scope verification requirements still apply.

The full-trust Electron/.NET/native helpers use process-launch APIs. WACK's
optional Blocked executables findings must be reviewed with the validation record;
they are disclosed, not claimed as waived Store policy. The app does not silently
change Windows security/accessibility policy. Unmanaged Home/Pro cannot guarantee
suppression of reserved secure-attention actions such as Ctrl+Alt+Delete. Stronger
school deployments require supported managed kiosk/Keyboard Filter policies.
