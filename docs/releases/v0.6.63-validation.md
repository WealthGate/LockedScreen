Date: 2026-11-18. Supervised-test candidate, not Microsoft certification or an
absolute-lockdown claim. The 0.6.62 fullscreen regression was reproduced using a
real Electron window: fullscreen flags could be true with only 900x600 coverage
on a 1920x1080 display. Use 0.6.63, not the older Store candidate.

## Release Gates

Follow `v0.6.63-acceptance-guide.md`, including both the isolated shortcut and a
signed private Store flight. Verify physical screen edges, actual native keyboard
behavior, normal invigilator exit, a second exam, real Google sign-in, Classroom
posting/assignment ID, student report and the expected grade. Automated Google
tests are fictional and did not post any real assignments or grades.

Across-PC grade publication still needs an authenticated teacher grade bridge;
hosted OAuth alone does not grant students teacher authority. Confirm Google
External/In production AND sensitive-scope approval; scope verification has not
been established by these local checks. School Workspace policies also apply.

Unmanaged Home/Pro cannot promise suppression of reserved secure-attention actions.
Managed kiosk/Keyboard Filter, touch/IME/accessibility, multiple users and privileged
tampering require separate supported Windows deployment validation.

Publish as a prerelease only. Stable automatic updates and the production Store
submission must remain unchanged until supervised acceptance and release review.
