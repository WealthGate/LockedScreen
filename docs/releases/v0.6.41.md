# Lockedscreen 0.6.41

## Improved

- Added a persistent `LOCKEDSCREEN v...` badge in the bottom-right corner so the running app version is always visible.
- Added a full-screen update handoff notice explaining that the Windows installer will open and the app will restart.
- Changed Windows updates from silent installation to the visible installer flow so students can see progress and follow any required prompts.
- Added a Windows notification when installation starts.
- Added an update-complete banner and notification after Lockedscreen restarts successfully on the new version.

## User Update

- The improved update experience applies to updates started from Lockedscreen `0.6.41` and later.
- Devices currently on `0.6.40` still use the previous updater during this one transition. Use the `0.6.41` standard installer manually when a visible installer is preferred.

## Validation

- Verified the version badge and installation notice in the renderer at the standard desktop viewport.
- Passed desktop tests, TypeScript checks, and the production Electron build.
