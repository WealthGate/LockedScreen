# Lockedscreen 0.6.39

## Fixed

- Fixed app-based Google Classroom exams failing LMS turn-in with a missing course or assignment reference.
- Classroom publishing now finalizes the attached `.lscp` package with the real assignment ID before making the assignment visible to students.
- Added safe assignment recovery for older affected packages when exactly one published assignment in the selected class matches the exam title.
- Improved the error shown when an older package cannot be matched safely and must be posted or exported again.

## Validation

- Added automated coverage for Classroom draft creation, package finalization, and assignment publishing order.
- Added automated coverage to prevent ambiguous assignment-title recovery.
