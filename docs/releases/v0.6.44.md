# Lockedscreen 0.6.44

## Fixed

- Fixed Google Classroom student turn-in attachment requests that could fail with `addAttachments...` errors.
- The Classroom Drive attachment payload now sends only the writable Drive file id instead of read-only Drive display fields.
- If Classroom still rejects the Drive file attachment, Lockedscreen now retries with a Drive link attachment.
- If every attachment attempt is rejected, Lockedscreen keeps going with Classroom turn-in and grade sync instead of blocking the whole LMS result flow.
- Added clearer messages when Google rejects Classroom submission changes because the assignment was not created by the same Lockedscreen Google app.

## User Update

- For best results, post/export the Classroom assignment directly from Lockedscreen using the connected teacher Google account. Google Classroom only allows automated attachment, turn-in, and grade updates from the same Google Cloud project that created the assignment.

## Validation

- Passed desktop Classroom attachment tests.
- Passed desktop tests, TypeScript checks, and the production Electron build.
