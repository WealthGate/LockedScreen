# Lockedscreen 0.6.42

## Fixed

- Improved Google Classroom grade write-back when Google rejects the first student submission id with a not-found response.
- The app now uses the signed-in student's email to ask the teacher-visible Classroom API for the correct submission before retrying the grade update.
- Replaced raw Google `Requested entity was not found` grade-sync failures with an actionable message that explains the teacher, student, assignment, and app-ownership checks.
- Kept grade scaling against the Classroom assignment's `maxPoints`, then writes both `assignedGrade` and `draftGrade` together.

## User Update

- Student email can help locate the correct grade record, but Google Classroom still requires the correct course, assignment, teacher permissions, and the same Google OAuth app that created/exported the assignment.

## Validation

- Passed desktop Google Classroom turn-in tests.
- Passed desktop TypeScript checks.
