# LockedScreen 0.6.65 Store Update

1. Complete `v0.6.65-acceptance-guide.md`. The signed-in Google Forms requirement
   remains unresolved on unmanaged PCs; do not submit this as a fix for that feature.
2. Open [Partner Center](https://partner.microsoft.com/dashboard) and select the
   existing LockedScreen product. Keep the registered identity and publisher.
3. Create a private package flight for the test accounts. Upload
   `apps/desktop/dist-store/LockedScreen-Store-0.6.65-x64.appx` under Packages.
   Expected identity is `WealthGate.LockedScreen`, version `0.6.65.0`, x64.
4. Add `v0.6.65-reviewer-instructions.md` to additional testing information, retain
   the privacy URL https://auth.whsdominica.com/privacy, review findings and submit
   the private flight for certification.
5. Install the signed flight through Microsoft Store and repeat the applicable
   Google, linked-control, fullscreen, switching and exit-PIN tests on each PC type.
6. Only after acceptance, update the public submission with this validated APPX
   and explicitly submit for certification. A local WACK pass is not Store approval.

The local test shortcut is `tmp/LockedScreen-0.6.65-Test.lnk`. It uses a separate
test profile and the built Store payload, not the installed production app.
GitHub installers are unsigned validation downloads. The APPX is a combined package,
not the online chooser, and does not offer smaller role-specific Store downloads.

[Microsoft package flights](https://learn.microsoft.com/en-us/windows/apps/publish/package-flights)
