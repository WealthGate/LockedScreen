# LockedScreen 0.6.64

Supervised-test prerelease with the simplified student Google flow:

1. Student Google sign-in finishes before exam lockdown begins.
2. Questions appear only after native lockdown and fullscreen checks pass.
3. Submit saves the local result, then starts configured LMS delivery automatically.
   No second PIN, external browser or lockdown release is needed for delivery.
4. The invigilator PIN is required only for final exit, including after submission.

Authorization refresh runs without browser interaction. Missing, expired or revoked
authorization never opens a browser inside a locked exam: the result stays saved
and lockdown remains active. Delivery and grade failures have separate status and
retry controls. Student Google consent does not grant teacher grading authority;
across-PC automatic grades still need an authenticated teacher grade bridge.

The secure-desktop path retains native enforcement. It uses an encrypted, one-use
student authorization handoff rather than placing credentials in process arguments.
Temporary student service credentials expire within twelve hours and are deleted
on normal exit when the service is reachable. Google refresh tokens and the
publisher Web client secret remain on the hosted service.

The hosted service and [privacy disclosure](https://auth.whsdominica.com/privacy)
are updated. Old teacher connections and old post-exam student clients remain
compatible. School-network rate limits support concurrent student sign-ins.

Use the small online chooser for selected Student/Teacher downloads. The Store
APPX remains one combined package. GitHub EXEs are unsigned validation downloads,
not a replacement for Store signing. Stable updates and the public Store product
are unchanged pending supervised acceptance.

See the [retest guide](https://github.com/WealthGate/LockedScreen/blob/codex/student-teacher-editions/docs/releases/v0.6.64-acceptance-guide.md)
and [validation record](https://github.com/WealthGate/LockedScreen/blob/codex/student-teacher-editions/docs/releases/v0.6.64-validation.md)
before Store submission. Do not reuse an older version's WACK result.
