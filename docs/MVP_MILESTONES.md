# MVP Milestones

1. **Core Domain**
   - Exam package model, grading engine, validation, PIN hashing.

2. **Local Storage**
   - JSON exam/results persistence.
   - CSV export.

3. **Import Pipeline**
   - DOCX to HTML conversion.
   - HTML rendering with MathJax.

4. **Examiner UI**
   - Create exam, import preview, answer key, publish package.

5. **Student UI**
   - Login, exam view, review, submit, results.

6. **Kiosk Helper**
   - Admin setup flow for Assigned Access.

7. **Docs & Tests**
   - Build/run steps, kiosk setup guidance, threat model.
   - Unit tests for grading and CSV.
